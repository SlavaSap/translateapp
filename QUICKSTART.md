# Быстрый старт

## Шаг 1: Установка зависимостей (2-5 минут)

### На Windows:
```powershell
cd TranslateApp
pip install -r requirements.txt
```

⚠️ **Первый запуск может быть долгим** - скачиваются большие модели OCR и переводчика (~1-2 ГБ)

## Шаг 2: Первый тест на ПК

```bash
python main.py
```

Откроется окно приложения. Нажмите "Скриншот" и потом "Перевести" для теста.

## Шаг 3: Тестирование голосовых команд

1. Нажмите "Начать слушание" в приложении
2. Разрешите доступ к микрофону (если спросит)
3. Произнесите четко: **"ТРАНСЛЕЙТ"**
4. Приложение автоматически:
   - Захватит скриншот
   - Распознает и переведет текст
   - Покажет результат

## Шаг 4: Сборка для Android (опционально)

### Установка Buildozer:
```bash
pip install buildozer cython
```

### Сборка:
```bash
buildozer android debug
```

Результат (APK файл) будет в папке `bin/`

## Основные команды

| Команда | Описание |
|---------|---------|
| `python main.py` | Запуск на ПК |
| `buildozer android debug` | Сборка debug APK |
| `buildozer android release` | Сборка release APK |

## Поддерживаемые команды голосом

- "ТРАНСЛЕЙТ"
- "TRANSLATE"
- "ПЕРЕВОДИТЬ"
- "ПЕРЕВОД"

## Что происходит при команде

1. 🎤 Микрофон слушает голос
2. 📸 Захватывается скриншот текущего экрана
3. 🔍 Текст распознается (OCR)
4. 🌐 Текст переводится на русский
5. 💬 Перевод показывается поверх оригинала

## Минимальные требования

- ОЗУ: 4 ГБ
- Место на диске: 2-3 ГБ (для моделей)
- Интернет: постоянное подключение
- Python 3.8+

## Если что-то не работает

### Ошибка при импорте easyocr
```bash
pip install --upgrade easyocr torch
```

### Ошибка при переводе
```bash
pip install --upgrade googletrans==4.0.46
```

### Микрофон не работает
- Проверьте в системе, подключен ли микрофон
- Проверьте уровень громкости
- Перезагрузите приложение

### OCR очень медленный
- Это нормально при первом запуске (~2-3 минуты)
- Модель кэшируется на диск
- Последующие запуски будут быстрее

## Следующие шаги

После успешного первого теста:
1. Измените языки поддерживаемые OCR в `src/ocr_engine.py`
2. Настройте внешний вид оверлея в `src/screen_capture.py`
3. Добавьте дополнительные команды в `src/voice_listener.py`
4. Соберите APK для своего Android устройства
