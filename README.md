# Translate App - Невидимое приложение для перевода

Приложение, которое распознаёт текст на скриншоте и переводит его на русский язык при команде "ТРАНСЛЕЙТ".

## Возможности

✅ Распознавание текста любого языка (OCR)
✅ Перевод на русский язык
✅ Замена текста на оверлее (поверх оригинала)
✅ Голосовая команда "ТРАНСЛЕЙТ"
✅ Полностью бесплатное решение
✅ Android приложение

## Требования

- Python 3.8+
- Android устройство (для мобильного приложения)
- Микрофон (для голосовых команд)
- Интернет (для Google Translate API)

## Установка для разработки (на Windows/Mac/Linux)

### 1. Установка зависимостей

```bash
cd TranslateApp
pip install -r requirements.txt
```

### 2. Первый запуск

```bash
python main.py
```

## Как использовать

### На ПК:
1. Запустите приложение: `python main.py`
2. Нажмите "Начать слушание"
3. Произнесите "ТРАНСЛЕЙТ"
4. Приложение автоматически:
   - Захватит скриншот
   - Распознает текст
   - Переведет его на русский
   - Покажет результат

### На Android:
1. Соберите APK: `buildozer android debug`
2. Установите на телефон
3. Запустите приложение
4. Разрешите необходимые разрешения (микрофон, доступ к экрану)
5. Произнесите "ТРАНСЛЕЙТ"

## Модули

### OCREngine (`src/ocr_engine.py`)
- Распознает текст на любом языке
- Поддерживает русский, английский, украинский, немецкий, французский, испанский, японский, китайский
- Возвращает текст с координатами и уверенностью

### TextTranslator (`src/translator.py`)
- Переводит текст на русский язык
- Определяет язык исходного текста
- Сохраняет позиции текста для оверлея

### ScreenCapture (`src/screen_capture.py`)
- Захватывает скриншот через ADB (для Android)
- Fallback через Kivy для ПК
- Сохраняет скриншоты в файлы

### VoiceListener (`src/voice_listener.py`)
- Слушает голосовые команды
- Распознает русскую речь
- Обнаруживает команду "ТРАНСЛЕЙТ"

## Технологии

- **Kivy** - фреймворк для мобильных приложений
- **EasyOCR** - распознавание текста
- **googletrans** - перевод текста
- **SpeechRecognition** - распознавание речи
- **Pillow** - обработка изображений
- **NumPy** - работа с массивами

## Возможные проблемы

### "No module named 'easyocr'"
```bash
pip install easyocr
```

### "No module named 'googletrans'"
```bash
pip install googletrans==4.0.46
```

### Микрофон не работает
- Проверьте разрешения на устройстве
- Убедитесь, что микрофон подключен
- Перезагрузите приложение

### OCR работает медленно
- Это нормально при первом запуске (загружается модель)
- На слабых устройствах может занимать несколько секунд
